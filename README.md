
# Prodigy InfoTech Data Science Internship

## Task 01 – Data Visualization

### Objective
Visualize the distribution of population across countries using a histogram and a bar chart.

### Dataset
World Bank Population Dataset

Source: https://data.worldbank.org/indicator/SP.POP.TOTL

### Tools and Libraries
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

### Work Performed
- Data loading and inspection
- Data cleaning and preprocessing
- Handling missing values
- Population distribution analysis
- Histogram visualization
- Bar chart visualization of the top 10 most populous countries
- Data interpretation

### Visualizations
1. Histogram showing population distribution across countries.
2. Bar chart comparing the population of the top 10 most populous countries.

### Conclusion
The visualizations demonstrate the unequal distribution of population across countries and highlight the differences between highly populated and less populated countries.

This task provided practical experience in data cleaning, exploratory data analysis, and data visualization using Python.
